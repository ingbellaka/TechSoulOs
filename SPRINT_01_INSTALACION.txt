TECHSOUL MANAGER — SPRINT 01 VISUAL v1.1

1. Haz una copia de seguridad de tu proyecto actual.
2. Copia los archivos de este paquete sobre tu proyecto y acepta reemplazar.
3. Abre PowerShell en la carpeta del proyecto.
4. Ejecuta:

   npm install
   npm run dev
