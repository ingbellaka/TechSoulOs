# TechSoul OS v1.2 beta 1

## Implementado
- Nuevo módulo funcional de Presupuestos.
- Conceptos múltiples, vigencia, estados y edición.
- Impresión directa y guardado como PDF mediante el navegador.
- Reutilización de precios guardados en el tarifario.
- TechSoul AI local conectado al tarifario y a presupuestos.
- Mensajes listos para WhatsApp y seguimiento de presupuestos.
- Reportes calculados con datos reales de caja, ventas, órdenes e inventario.
- Exportación de resumen a CSV.
- Fotografías de recepción continúan siendo opcionales.

## Alcance de IA
El asistente incluido funciona localmente mediante reglas y los datos registrados. No utiliza todavía una API externa de inteligencia artificial. Esto evita costos y exposición de datos mientras se valida el flujo del negocio.

## Validación recomendada
1. npm install
2. npm run build
3. npm run dev
